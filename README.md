# Rosalind Bioinformatics Stronghold Problems

This repository contains 36 problems I solved from Rosalind, and few reusable utility files. 
I have shared the algorithms used and things I learned from each problem.
I have tried not using the predefined modules for bioinformatics as algorithm designing was the main focus.

## Utility Files
|                              File                              | Description                                                                                                                                                                                                                                                                                                                                                                        | Returns                                                                                                                                                                                                                                                                                                                                                                           |
|:--------------------------------------------------------------:|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|                    [`fasta.py`](./fasta.py)                    | Reads input in fasta format.                                                                                                                                                                                                                                                                                                                                                       | A dictionary with ID as keys and DNA strands as values.                                                                                                                                                                                                                                                                                                                           |
|                    [`Motif.py`](./Motif.py)                    | To treat motifs equivalent to strings. It also stores the information of the positions that allow for multiple codons.<br>Subclass `Inc` of `Motif` accounts for [XY]: "either X or Y"<br> Subclass `Exc` of `Motif` accounts for {X}: "any amino acid except X"                                                                                                                   | An object of class `Motif` with behaviours such as len, == operation with strings & indexing defined.                                                                                                                                                                                                                                                                             |
|                   [`Streak.py`](./Streak.py)                   | To maintain character streaks while finding substrings.<br>`streak` function finds all occurences of a substring.<br>`istreak` function allows for streaking interactively, allowing to update the substring in each iteration and also get some output each iteration according to some query.<br>`multi` function finds all occurences of multiple substrings in a given string. | `streak` returns a set of all starting indices of the substring.<br>`istreak` returns a generator object which yields the output to some query (a function on the streak set to be passed while calling) after each checking each character of the string.<br>`multi` returns a dictionary containing substrings as keys and sets of their intial indices of occurence as values. |
|                  [`uniprot.py`](./uniprot.py)                  | Fetch protein data from uniprot database from the ID of the protein.                                                                                                                                                                                                                                                                                                               | A dictionary containing all data about the protein.<br>`uniprot(f"{ID}")["sequence"]["value"]` returns the string containing the DNA strand.                                                                                                                                                                                                                                      |
|        [`RNA_Codon_Table.txt`](./RNA_Codon_Table.txt)          | A table indicating the translation of individual RNA codons into amino acids in JSON format.                                                                                                                                                                                                                                                                                       | `json.loads(open("RNA_Codon_Table.txt").read())` returns a dictionary having RNA codons as keys and corresponding amino acid as values.                                                                                                                                                                                                                                           |
| [`Monoisotopic_Mass_Table.txt`](./Monoisotopic_Mass_Table.txt) | A table storing mass of all amino acids in JSON format.                                                                                                                                                                                                                                                                                                                            | `json.loads(open("Monoisotopic_Mass_Table.txt").read())` returns a dictionary having amino acids as keys and their masses as values.                                                                                                                                                                                                                                              |
